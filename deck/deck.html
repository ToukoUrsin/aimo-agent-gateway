Who decides what

Rules run in code. Never in a model.

  • The buyer signs a mandate. How much, which products, which substitutes. Valio Aimo has its own switch and cap on top.
  • {{rules}} named rules on every request. Pass, ask a person, or refuse. Nobody can approve what a rule refused.
  • The yes is signed on the approver's own phone. A passkey. The key never leaves the device, so no agent and no server can make that approval.
  • Everything is signed. Change one cent in an order and the check fails in your browser.
