This is Valio Aimo's own agent, speaking in its name and signing with its key. It proposes; the kitchen's agent and the kitchen's people decide.

How it is kept in line

Every proposal is a signed offer, judged by the same rules as any order under the buyer's mandate before it leaves. Code picks the products, quantities and prices. A model only chooses which proposals matter today and writes the sentence. Short-dated stock is never offered as extra the kitchen would not use before the date, and a change to a standing order always goes to a person at the kitchen unless the buyer's mandate says otherwise.
